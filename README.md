# Simple Hotel Booking Form

This example provides a simple, self-contained HTML form for direct hotel bookings. It includes fields for guest information, dates, number of guests, and room type, demonstrating a basic direct reservation interface.

## Language

`html`

## How to Run

Save the code as `booking_form.html` and open it in any web browser.
